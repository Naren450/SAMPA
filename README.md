# SAMPA
Segment Anything Model for Plant Image Analysis (SAMPA)

## Software availability
SAMPA is a compiled MATLAB R2025b application for interactive segmentation and quantitative phenotyping of root and shoot images.
Compiled executables for Windows and Linux are distributed through GitHub Releases. The MATLAB source code is not publicly distributed.
Users should download the appropriate platform-specific package, install MATLAB Runtime R2025b if required, and follow the installation instructions in the user guide.
The repository also provides documentation, example images, representative segmentation outputs, and trait-validation results.
