# SAMPA
Segment Anything Model for Plant Image Analysis (SAMPA)
> Abstract
Quantitative image-based analysis of plant root and shoot systems is foundational to modern plant phenotyping, yet it remains constrained by the need for specialized segmentation models and programming expertise. Here we present SAMPA (Segment Anything Model for Plant Image Analysis), an open-source MATLAB application that integrates Meta's Segment Anything Model (SAM) into an intuitive compiled graphical user interface (GUI) for high-throughput, multi-instance plant (root and shoot) image segmentation and phenotypic trait extraction. SAMPA supports three interactive prompt modalities—point, bounding box, and polygon—enabling users to segment and label individual plant organs without programming knowledge. Each user-defined region of interest (ROI) is assigned a unique Label ID, and phenotypic traits are computed both per-label and for the entire image simultaneously. Segmented plant organs are displayed as colour-coded labels, and users can remove and /or modify labels, clear internal regions, or process an entire image without segmentation. After selecting either root or shoot mode, SAMPA extracts system-specific morphological and spatial traits that characterize plant growth. Distributed as a standalone MATLAB compiled application, SAMPA requires no MATLAB license for end users and runs on standard laboratory workstations. SAMPA substantially reduces the technical barrier to deep learning–assisted plant phenotyping and is designed for direct integration into existing laboratory image analysis workflows.
